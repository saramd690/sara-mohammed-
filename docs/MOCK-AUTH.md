# وضع المصادقة الوهمي

لتجربة شكل بيانات الأدوار محليًا، اضبط `NEXT_PUBLIC_MOCK_AUTH=true` في `.env.local` ثم افتح `/mock-auth`. المسار `POST /api/v1/mock/login` يقبل الدور ويرجع هوية تجريبية ثابتة.

هذا محاكي بيانات وليس جلسة مصادقة فعلية: لا يمنح وصولًا إلى قاعدة البيانات أو المسارات المحمية، ويُرفض تلقائيًا في بيئة الإنتاج. لا تستخدمه للتحقق الأمني أو اختبارات صلاحيات حقيقية.
